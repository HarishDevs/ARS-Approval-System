# 03 · Existing module reusability

Recommendation in one line: **extend the existing Task Management module; do not build a second one.** Almost all foundations (tasks, history, files, comments, permissions, holidays, reminders, analytics) exist and are tested. New work is concentrated in acknowledgement, delegation, checklists, leave, IDM meetings and the Daily Work Report.

| # | Component | What exists | Where | How to reuse | Changes needed | Risk |
|---|---|---|---|---|---|---|
| 1 | Authentication | Google, password + WhatsApp code, sessions | `server/auth/**`, `lib/session/**` | Use as is | None | None |
| 2 | Users, departments, designations, reporting lines | `users` (reporting_manager_id, department_id, designation_id, module_access), `departments` (hod_user_id), `designations`, `groups` | `lib/db/repositories/admin-users.repository.ts`, `app/admin/users`, `app/admin/organisation`, `app/admin/groups` | Single source of employees, HODs, managers and teams | None (no duplicate employee tables) | None |
