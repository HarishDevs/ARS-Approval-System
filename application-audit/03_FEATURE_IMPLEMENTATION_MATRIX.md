# 03 — Feature implementation matrix

ARS Approval Platform v1.8.0 (commit `168216a`), audited 16 Oct 2026. Read-only audit; nothing in the application was changed.

## How to read this matrix

- **Implemented — Verified:** code exists, and the tests named in *Test evidence* passed in the local run of 16 Oct 2026. That run covered:
  - lint and typecheck;
  - unit tests: 433 passed;
  - integration tests against MySQL 8 in Docker: 188 passed;
  - Playwright E2E: 92 passed;
  - QA and origin-lock suites (results in `10_TESTING_AND_VERIFICATION_PLAN.md`).

  These are local, automated results. Nothing was run against production.
- **Implemented — Code Verified:** the code path was read and is consistent, but no named test covers it, or only the loader QA suite does (that suite is outside CI and was not run).
- **Broken:** evidence shows wrong behaviour. Four rows were **confirmed at runtime** by throwaway probe tests that the lead auditor ran from a scratch folder; they are not added to the repo, and the *Note* column marks them.
- **Partially Implemented / Not Implemented:** see *Missing work*.
- Rows come from the domain audits, each cross-checked: authentication (`AUTH-`), engine and requests (`WF-`, `REQ-`), Admin (`ADM-`), Super Admin (`SA-`), user utility pages (`USR-`), analytics (`AN-`), reports (`RPT-`), notifications (`NOT-`), jobs (`JOB-`), integrations (`INT-`) and operations (`OPS-`).
- Abbreviations: int = `tests/integration`, unit = `tests/**` unit tests, e2e = `tests/e2e`, S = server-side check. Evidence is `file:line` from the repo root.
